## A1 — exact frozen-AOV historical replay

A1 is an **exploratory historical measurement of the incumbent**, not permission to redesign it.

The replay must bind the already-current AOV semantics rather than invent a historical variant:

- frozen Rule100 / Parent / Child logic;
- frozen insurance V0;
- exact economic-cash law;
- canonical CIQ security identity and explicit historical identity mapping;
- PIT/as-of fundamentals and source availability semantics;
- completed market-return authority;
- declared execution calendar / transaction-cost semantics;
- immutable input and executable hashes;
- explicit historical universe/risk-set contract and its limitations.

Primary A1 economic questions:

```text
Does Parent compound?
Does Child improve Parent net of costs?
Where does Child help?
Where does Child destroy return?
Which losses dominate?
Which eventual winners are never entered / under-sized / cut too early?
How much return is concentration / right-tail dependent?
```

A1 does not tune Parent/Child in place. A1 findings may create diagnostics and future hypotheses/search debt only.

## A2 — untouched historical PIT OOS

A2 is query-metered hidden historical OOS. It is not a broad exploratory playground.

Requirements:

- outcome bytes remain inaccessible before the frozen A2 query;
- evaluation uses the exact frozen AOV object declared at the A2 freeze;
- the query and result are append-only and hash-bound;
- no threshold, universe, cost, timing, target, or metric is changed after seeing the result under the same version;
- A2 failure remains visible and cannot be rewritten into success;
- A2 does not become prospective evidence and does not change `financial_alpha_evidence=0`.

If legitimate historical PIT universe membership / source availability cannot support the claimed evaluation, classify the result explicitly as a bounded diagnostic (for example `CURRENT_SCREEN_CONDITIONED_DIAGNOSTIC`) rather than promoting it to A1/A2 evidence.
